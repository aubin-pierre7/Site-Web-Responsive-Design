#  Aubin House Burger  

Un site vitrine responsive pour le restaurant *Aubin House Burger*, réalisé dans le cadre d’un devoir scolaire.  
Le projet utilise *HTML5* et *CSS3* afin d’assurer une navigation fluide et une mise en page adaptée à tous les écrans (ordinateur, tablette, mobile).  

---

## 📌 Objectif du projet  
- Mettre en pratique les bases du *HTML* et du *CSS*.  
- Créer un site *responsive design* en utilisant *Flexbox* et/ou *Grid*.  
- Présenter un restaurant fictif avec une identité visuelle simple et moderne.  

---

## 🖥 Fonctionnalités  
- Page d’accueil présentant le restaurant.  
- Menu avec différentes catégories de burgers et boissons.  
- Section "À propos" avec l’histoire du restaurant.  
- Formulaire de contact (HTML uniquement, sans backend).  
- Design responsive :  
  - 📱 Mobile  
  - 💻 Ordinateur  
  - 📟 Tablette  

---

## ⚙ Technologies utilisées  
- *HTML5*  
- *CSS3* (Flexbox, Media Queries, éventuellement Grid)
