# Aubin's Burger House 

Un site vitrine responsive pour le restaurant *Aubin's Burger House*, realise dans le cadre d’un devoir.  


## Objectif du projet  
- Mettre en pratique les bases du *HTML* et du *CSS*.  
- Creer un site *responsive design* en utilisant des  *Flexbox* et des *Grid*.  
- Presenter un restaurant fictif avec une identite visuelle simple et moderne.


## Technologies utilisées  
- *HTML5*  
- *CSS3*
